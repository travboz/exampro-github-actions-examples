Single vs multiple trigger events

Single trigger 
on:
  push:
    branches: [ main ]

Only one trigger: a push to the main branch.

Multiple triggers 
on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main
  release:
    types:
      - published
      - created

Three triggers: a push to main, a pull request into main, or a release with types published or created.

⚠ If any of these fire simultaneously → multiple workflow runs will occur.
